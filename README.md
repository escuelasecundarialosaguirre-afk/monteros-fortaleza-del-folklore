
# Monteros – Fortaleza del Folklore

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sitio web informativo sobre la ciudad de Monteros, ubicada en la provincia de Tucumán, Argentina.

El objetivo es dar a conocer su identidad cultural, sus lugares representativos, sus tradiciones y algunas de las celebraciones que forman parte de su historia y patrimonio local.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.2
- Bootstrap Icons

## Secciones y funcionalidades

El sitio web cuenta con diferentes secciones:

- **Conocé Monteros:** información general sobre la ciudad.
- **Lugares representativos:** presentación de espacios y sitios destacados.
- **Contenido interactivo:** utilización de componentes de Bootstrap.
- **Cultura y tradiciones:** información sobre fiestas, artesanías y celebraciones locales.
- **Barra de navegación:** permite recorrer las distintas secciones del sitio.
- **Contacto:** incluye un acceso directo a WhatsApp.

## Tienda de productos regionales

El proyecto incorpora una tienda demostrativa con productos representativos de la región, como mates y sombreros.

Los precios son ficticios y se utilizan exclusivamente con fines académicos para mostrar la presentación de productos y la interacción con el carrito de compras.

Esta sección no procesa compras ni realiza ventas reales.
